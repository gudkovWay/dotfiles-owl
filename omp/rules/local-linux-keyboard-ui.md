# Клавиатурный UI персонального Linux

**Область — только личный Linux-десктоп/интерфейс владельца.** Правило не
применяется к `p2p-frontend` и к рабочим/клиентским/продуктовым репозиториям:
то, что они локальные и на Linux, областью их не делает.

Если запрос про клавиатурное взаимодействие личного интерфейса — сначала
прочитай `skill://local-linux-keyboard-ui`; если `skill://` не резолвится,
прочитай авторитетный файл напрямую:
`/home/q/.agents/skills/local-linux-keyboard-ui/SKILL.md` — до любого нового
поиска по системе.

Правило — только указатель. Процедура целиком живёт в скилле и здесь не
дублируется.
